3858!> \namespace mom_vert_friction
3859!! \author Robert Hallberg
3860!! \date April 1994 - October 2006
3861!!
3862!! The vertical diffusion of momentum is fully implicit. This is
3863!! necessary to allow for vanishingly small layers. The coupling
3864!! is based on the distance between the centers of adjacent layers,
3865!! except where a layer is close to the bottom compared with a
3866!! bottom boundary layer thickness when a bottom drag law is used.
3867!! A stress top b.c. and a no slip bottom b.c. are used. There
3868!! is no limit on the time step for vertvisc.
3869!!
3870!! Near the bottom, the horizontal thickness interpolation scheme
3871!! changes to an upwind biased estimate to control the effect of
3872!! spurious Montgomery potential gradients at the bottom where
3873!! nearly massless layers layers ride over the topography. Within a
3874!! few boundary layer depths of the bottom, the harmonic mean
3875!! thickness (i.e. (2 h+ h-) / (h+ + h-) ) is used if the velocity
3876!! is from the thinner side and the arithmetic mean thickness
3877!! (i.e. (h+ + h-)/2) is used if the velocity is from the thicker
3878!! side. Both of these thickness estimates are second order
3879!! accurate. Above this the arithmetic mean thickness is used.
3880!!
3881!! In addition, vertvisc truncates any velocity component that exceeds a
3882!! maximum CFL number to a fraction of this value. This basically keeps
3883!! instabilities spatially localized. The number of times the velocity is
3884!! truncated is reported each time the energies are saved, and if
3885!! exceeds CS%Maxtrunc the model will stop itself and change the time
3886!! to a large value. This has proven very useful in (1) diagnosing
3887!! model failures and (2) letting the model settle down to a
3888!! meaningful integration from a poorly specified initial condition.
3889!!
3890!! The same code is used for the two velocity components, by
3891!! indirectly referencing the velocities and defining a handful of
3892!! direction-specific defined variables.
3893!!
3894!! Macros written all in capital letters are defined in MOM_memory.h.
3895!!
3896!! A small fragment of the grid is shown below:
3897!! \verbatim
3898!! j+1 x ^ x ^ x At x: q
3899!! j+1 > o > o > At ^: v, frhatv, tauy
3900!! j x ^ x ^ x At >: u, frhatu, taux
3901!! j > o > o > At o: h
3902!! j-1 x ^ x ^ x
3903!! i-1 i i+1 At x & ^:
3904!! i i+1 At > & o:
3905!! \endverbatim
3906!!
3907!! The boundaries always run through q grid points (x).
39080end module MOM_vert_friction
