735!> Stream function shape as a function of non-dimensional position within mixed-layer [nondim]
7360real function mu(sigma, dh)
737 real, intent(in) :: sigma !< Fractional position within mixed layer [nondim]
738 !! z=0 is surface, z=-1 is the bottom of the mixed layer
739 real, intent(in) :: dh !< Non-dimensional distance over which to extend stream
740 !! function to smooth transport at base [nondim]
741 ! Local variables
742 real :: xp !< A linear function from mid-point of the mixed-layer
743 !! to the extended mixed-layer bottom [nondim]
744 real :: bottop !< A mask, 0 in upper half of mixed layer, 1 otherwise [nondim]
745 real :: dd !< A cubic(-ish) profile in lower half of extended mixed
746 !! layer to smooth out the parameterized transport [nondim]
747
748 ! Lower order shape (not used), see eq 10 from FK08b.
749 ! Apparently used in CM2G, see eq 14 of FK11.
750 !mu = max(0., (1. - (2.*sigma + 1.)**2))
751
752 ! Second order, in Rossby number, shape. See eq 21 from FK08a, eq 9 from FK08b, eq 5 FK11
7530 mu = max(0., (1. - (2.*sigma + 1.)**2) * (1. + (5./21.)*(2.*sigma + 1.)**2))
754
755 ! -0.5 < sigma : xp(sigma)=0 (upper half of mixed layer)
756 ! -1.0+dh < sigma < -0.5 : xp(sigma)=linear (lower half +dh of mixed layer)
757 ! sigma < -1.0+dh : xp(sigma)=1 (below mixed layer + dh)
7580 xp = max(0., min(1., (-sigma - 0.5)*2. / (1. + 2.*dh)))
759
760 ! -0.5 < sigma : dd(sigma)=1 (upper half of mixed layer)
761 ! -1.0+dh < sigma < -0.5 : dd(sigma)=cubic (lower half +dh of mixed layer)
762 ! sigma < -1.0+dh : dd(sigma)=0 (below mixed layer + dh)
7630 dd = (max(1. - xp**2 * (3. - 2.*xp), 0.))**(1. + 2.*dh)
764
765 ! -0.5 < sigma : bottop(sigma)=0 (upper half of mixed layer)
766 ! sigma < -0.5 : bottop(sigma)=1 (below upper half)
7670 bottop = 0.5*(1. - sign(1., sigma + 0.5)) ! =0 for sigma>-0.5, =1 for sigma<-0.5
768
7690 mu = max(mu, dd*bottop) ! Combines original psi1 with tail
7700end function mu

2138!! \section section_mle Mixed-layer eddy parameterization module
2139!!
2140!! The subroutines in this module implement a parameterization of unresolved viscous
2141!! mixed layer restratification of the mixed layer as described in \cite fox-kemper2008,
2142!! and whose impacts are described in \cite fox-kemper2011.
2143!! This is derived in part from the older parameterization that is described in
2144!! \cite Hallberg2003, which this new parameterization surpasses, which
2145!! in turn is based on the sub-inertial mixed layer theory of \cite Young1994.
2146!! There is no net horizontal volume transport due to this parameterization, and
2147!! no direct effect below the mixed layer. A revised version of the parameterization by
2148!! \cite Bodner2023 is also available as an option.
2149!!
2150!! This parameterization sets the restratification timescale to agree with
2151!! high-resolution studies of mixed layer restratification.
2152!!
2153!! The run-time parameter <code>FOX_KEMPER_ML_RESTRAT_COEF</code> is a non-dimensional number of
2154!! order a few tens, proportional to the ratio of the deformation radius or the
2155!! grid scale (whichever is smaller) to the dominant horizontal length-scale of the
2156!! sub-meso-scale mixed layer instabilities.
2157!!
2158!! \subsection section_mle_nutshell "Sub-meso" in a nutshell
2159!!
2160!! The parameterization is colloquially referred to as "sub-meso".
2161!!
2162!! The original \cite fox-kemper2008-2 paper proposed a quasi-Stokes
2163!! advection described by the stream function (eq. 5 of \cite fox-kemper2011):
2164!! \f[
2165!! {\bf \Psi}_o = C_e \frac{ H^2 \nabla \bar{b} \times \hat{\bf z} }{ |f| } \mu(z)
2166!! \f]
2167!!
2168!! where the vertical profile function is
2169!! \f[
2170!! \mu(z) = \max \left\{ 0, \left[ 1 - \left(\frac{2z}{H}+1\right)^2 \right]
2171!! \left[ 1 + \frac{5}{21} \left(\frac{2z}{H}+1\right)^2 \right] \right\}
2172!! \f]
2173!! and \f$ H \f$ is the mixed-layer depth, \f$ f \f$ is the local Coriolis parameter, \f$ C_e \sim 0.06-0.08 \f$ and
2174!! \f$ \nabla \bar{b} \f$ is a depth mean buoyancy gradient averaged over the mixed layer.
2175!!
2176!! For use in coarse-resolution models, an upscaling of the buoyancy gradients and adaption for the equator
2177!! leads to the following parameterization (eq. 6 of \cite fox-kemper2011):
2178!! \f[
2179!! {\bf \Psi} = C_e \Gamma_\Delta \frac{\Delta s}{l_f} \frac{ H^2 \nabla \bar{b} \times \hat{\bf z} }
2180!! { \sqrt{ f^2 + \tau^{-2}} } \mu(z)
2181!! \f]
2182!! where \f$ \Delta s \f$ is the minimum of grid-scale and deformation radius,
2183!! \f$ l_f \f$ is the width of the mixed-layer fronts, and \f$ \Gamma_\Delta=1 \f$.
2184!! \f$ \tau \f$ is a time-scale for mixing momentum across the mixed layer.
2185!! \f$ l_f \f$ is thought to be of order hundreds of meters.
2186!!
2187!! The upscaling factor \f$ \frac{\Delta s}{l_f} \f$ can be a global constant, model parameter
2188!! <code>FOX_KEMPER_ML_RESTRAT</code>, so that in practice the parameterization is:
2189!! \f[
2190!! {\bf \Psi} = C_e \Gamma_\Delta \frac{ H^2 \nabla \bar{b} \times \hat{\bf z} }{ \sqrt{ f^2 + \tau^{-2}} } \mu(z)
2191!! \f]
2192!! with non-unity \f$ \Gamma_\Delta \f$.
2193!!
2194!! \f$ C_e \f$ is hard-coded as 0.0625. \f$ \tau \f$ is calculated from the surface friction velocity \f$ u^* \f$.
2195!!
2196!! \todo Explain expression for momentum mixing time-scale.

2204!! \subsection section_mle_filtering Time-filtering of mixed-layer depth
2205!!
2206!! Using the instantaneous mixed-layer depth is inconsistent with the finite life-time of
2207!! mixed-layer instabilities. We provide a one-sided running-mean filter of mixed-layer depth, \f$ H \f$, of the form:
2208!! \f[
2209!! \bar{H} \leftarrow \max \left( H, \frac{ \Delta t H + \tau_h \bar{H} }{ \Delta t + \tau_h } \right)
2210!! \f]
2211!! which allows the effective mixed-layer depth seen by the parameterization, \f$\bar{H}\f$, to instantaneously deepen
2212!! but to decay with time-scale \f$ \tau_h \f$.
2213!! \f$ \bar{H} \f$ is substituted for \f$ H \f$ in the above equations.
2214!!
2215!! | Symbol | Module parameter |
2216!! | ---------------------------- | --------------------- |
2217!! | \f$ \tau_h \f$ | MLE_MLD_DECAY_TIME |
2218!!
2219!! \subsection section_mle_mld Defining the mixed-layer-depth
2220!!
2221!! If the parameter MLE_USE_PBL_MLD=True then the mixed-layer depth is defined/diagnosed by the
2222!! boundary-layer parameterization (e.g. ePBL, KPP, etc.).
2223!!
2224!! If the parameter MLE_USE_PBL_MLD=False then the mixed-layer depth is diagnosed in this module
2225!! as the depth of a given density difference, \f$ \Delta \rho \f$, with the surface where the
2226!! density difference is the parameter MLE_DENSITY_DIFF.
2227!!
2228!! \subsection The Bodner (2023) modification
2229!!
2230!! To use this variant of the parameterization, set MLE\%USE_BODNER23=True which then changes the
2231!! available parameters.
2232!! MLE_USE_PBL_MLD must be True to use the B23 modification.
2233!!
2234!! \cite Bodner2023, (B23) use an expression for the frontal width which changes the scaling from \f$ H^2 \f$
2235!! to \f$ h H^2 \f$:
2236!! \f[
2237!! {\bf \Psi} = C_r \frac{\Delta s |f| \bar{h} \bar{H}^2 \nabla \bar{b} \times \hat{\bf z} }
2238!! { \left( m_*u_*^3 + n_* w_*^3 \right)^{2/3} } \mu(z)
2239!! \f]
2240!! (see eq. 27 of B23).
2241!! Here, the \f$h\f$ is the activate boundary layer depth, and \f$H\f$ is the mixed layer depth.
2242!! The denominator is an approximation of the vertical turbulent momentum flux \f$\overline{w'u'}\f$ (see
2243!! eq. 18 of B23) calculated from the surface friction velocity \f$u_*\f$, and from the surface buoyancy flux,
2244!! \f$B\f$, using the relation \f$ w_*^3 \sim -B h \f$.
2245!! An advantage of this form of "sub-meso" is the denominator is well behaved at the equator but we apply a
2246!! lower bound of \f$w_{min}^2\f$ to avoid division by zero under zero forcing.
2247!! As for the original Fox-Kemper parameterization, \f$\nabla \bar{b}\f$ is the buoyancy gradient averaged
2248!! over the mixed-layer.
2249!!
2250!! The instantaneous boundary layer depth, \f$h\f$, is time filtered primarily to remove the diurnal cycle:
2251!! \f[
2252!! \bar{h} \leftarrow \max \left(
2253!! \min \left( h, \frac{ \Delta t h + \tau_{h+} \bar{h} }{ \Delta t + \tau_{h+} } \right),
2254!! \frac{ \Delta t h + \tau_{h-} \bar{h} }{ \Delta t + \tau_{h-} } \right)
2255!! \f]
2256!! Setting \f$ \tau_{h+}=0 \f$ means that when \f$ h>\bar{h} \f$ then \f$\bar{h}\leftarrow h\f$, i.e. the
2257!! effective (filtered) depth, \f$\bar{h}\f$, is instantly deepened. When \f$h<\bar{h}\f$ then the effective
2258!! depth shoals with time-scale \f$\tau_{h-}\f$.
2259!!
2260!! A second filter is applied to \f$\bar{h}\f$ to yield and effective "mixed layer depth", \f$\bar{H}\f$,
2261!! defined as the deepest the boundary layer over some time-scale \f$\tau_{H-}\f$:
2262!! \f[
2263!! \bar{H} \leftarrow \max \left(
2264!! \min \left( \bar{h}, \frac{ \Delta t \bar{h} + \tau_{H+} \bar{H} }{ \Delta t + \tau_{H+} } \right),
2265!! \frac{ \Delta t \bar{h} + \tau_{h-} \bar{H} }{ \Delta t + \tau_{H-} } \right)
2266!! \f]
2267!! Again, setting \f$ \tau_{H+}=0 \f$ allows the effective mixed layer to instantly deepend to \f$ \bar{h} \f$.
2268!!
