2109!! Runge-Kutta time stepping scheme for the baroclinic momentum
2110!! equation and a forward-backward coupling between the baroclinic
2111!! momentum and continuity equations. This split time-stepping
2112!! scheme is described in detail in Hallberg (JCP, 1997). Additional
2113!! issues related to exact tracer conservation and how to
2114!! ensure consistency between the barotropic and layered estimates
2115!! of the free surface height are described in Hallberg and
2116!! Adcroft (Ocean Modelling, 2009). This was the time stepping code
2117!! that is used for most GOLD applications, including GFDL's ESM2G
2118!! Earth system model, and all of the examples provided with the
2119!! MOM code (although several of these solutions are routinely
2120!! verified by comparison with the slower unsplit schemes).
2121!!
2122!! The subroutine step_MOM_dyn_split_RK2 actually does the time
2123!! stepping, while register_restarts_dyn_split_RK2 sets the fields
2124!! that are found in a full restart file with this scheme, and
2125!! initialize_dyn_split_RK2 initializes the cpu clocks that are
2126!! used in this module. For largely historical reasons, this module
2127!! does not have its own control structure, but shares the same
2128!! control structure with MOM.F90 and the other MOM_dynamics_...
2129!! modules.
