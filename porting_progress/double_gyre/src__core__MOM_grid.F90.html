467 integer, intent(in) :: j !< j index of cell to test

469 real, intent(in) :: y !< y coordinate of point [degrees_N]

472 real :: yNE, yNW, ySE, ySW ! Latitudes of cell corners [degrees_N]
473 real :: l0, l1, l2, l3 ! Crossed products of differences in position [degrees_E degrees_N]
474 real :: p0, p1, p2, p3 ! Trinary unitary values reflecting the signs of the crossed products [nondim]

4830 return ! Avoid the more complicated calculation

4860 l1 = (x-xSE)*(yNE-ySE) - (y-ySE)*(xNE-xSE)

4930 p3 = sign(1., l3) ; if (l3 == 0.) p3=0.
494
4950 if ( (abs(p0)+abs(p2)) + (abs(p1)+abs(p3)) == abs((p0+p2) + (p1+p3)) ) then

653!> \namespace mom_grid
654!!
655!! Grid metrics and their inverses are labelled according to their staggered location on a Arakawa C (or B) grid.
656!! - Metrics centered on h- or T-points are labelled T, e.g. dxT is the distance across the cell in the x-direction.
657!! - Metrics centered on u-points are labelled Cu (C-grid u location). e.g. dyCu is the y-distance between
658!! two corners of a T-cell.
659!! - Metrics centered on v-points are labelled Cv (C-grid v location). e.g. dyCv is the y-distance between two -points.
660!! - Metrics centered on q-points are labelled Bu (B-grid u,v location). e.g. areaBu is the area centered on a q-point.
661!!
662!! \image html Grid_metrics.png "The labelling of distances (grid metrics) at various staggered
663!! location on an T-cell and around a q-point."
664!!
665!! Areas centered at T-, u-, v- and q- points are `areaT`, `areaCu`, `areaCv` and `areaBu` respectively.
666!!
667!! The reciprocal of metrics are pre-calculated and also stored in the ocean_grid_type with a I prepended to the name.
668!! For example, `1./areaT` is called `IareaT`, and `1./dyCv` is `IdyCv`.
669!!
670!! Geographic latitude and longitude (or model coordinates if not on a sphere) are stored in
671!! `geoLatT`, `geoLonT` for T-points.
672!! u-, v- and q- point coordinates are follow same pattern of replacing T with Cu, Cv and Bu respectively.
673!!
674!! Each location also has a 2D mask indicating whether the entire column is land or ocean.
675!! `mask2dT` is 1 if the column is wet or 0 if the T-cell is land.
676!! `mask2dCu` is 1 if both neighboring columns are ocean, and 0 if either is land.
677!! `OBCmasku` is 1 if both neighboring columns are ocean, and 0 if either is land of if this is OBC point.
678
6790end module MOM_grid
